Phonlet Wake on ESP32-S3.

The ESP-IDF component: measured CPU, memory and delay, and how to build it in.

Phonlet Wake runs on ESP32-S3. The engine ships as an ESP-IDF component with its own code for the chip’s vector instructions, and a demo firmware streams an I2S microphone through it. Any phrase you type becomes a wake word on the device, with no recordings and no per-word training.

esp32-s3

Example

Embed the model in flash, describe your phrases as JSON (each phrase’s pronunciations and two calibrated thresholds), start the engine once, and pass every I2S read to it:

main.c
1#include <stdio.h>2#include "esp_wake.h"3 4// A phrase is its pronunciations and two calibrated thresholds.5static const char keywords[] =6    "[{\"name\": \"hey kettle\","7    "  \"pronunciations\": [[16, 13, 20, 11, 31, 3, 21]],"8    "  \"threshold_loose\": -1.21875,"9    "  \"threshold_strict\": -0.8740234375,"10    "  \"endpoint\": true}]";11 12// The model, embedded in flash.13extern const uint8_t model[] asm("_binary_model_pwake_start");14extern const uint8_t model_end[] asm("_binary_model_pwake_end");15 16static pw_wake *wake;17 18void start(void) {19  if (esp_wake_begin(model, model_end - model, keywords, 0.5f,20                     &wake) != PW_OK)21    printf("Wake init failed: %s\n", phonlet_wake_error());22}23 24// Push 16 kHz mono int16 PCM from the I2S microphone.25void on_audio(const int16_t *pcm, int32_t samples) {26  int32_t fired;27  esp_wake_feed(wake, pcm, samples, &fired);28  if (fired >= 0)29    printf("Wake word: %s\n", esp_wake_keyword_name(fired));30}

Measured on hardware

An ESP32-S3-N16R8 at 240 MHz with 8 MB of octal PSRAM, an INMP441 microphone, ESP-IDF 5.4, and six phrases listening at once (31 October 2026). In the first live test on this board, each of the six phrases was detected when spoken.

The engine works through a few 32 ms frames at a time to save memory traffic. One configuration setting trades CPU for response time; it changes when a detection is reported, not which phrases are detected:

SettingAdded delayCPU (one core)
Fastest response0 ms46%
Balanced32 ms28%
Default96 ms19%
Lowest CPU224 ms16%

The second core stays free for your application, Wi-Fi, or audio playback.

What your board needs

  • An ESP32-S3 with PSRAM. The model’s weights take about 1 MB: 75 KB in internal RAM, the rest in PSRAM.
  • An I2S MEMS microphone, read at 16 kHz.
  • One mono audio stream. Microphone arrays, voice activity detection, and noise suppression stay in your own audio pipeline, in front of the engine.

Get the component

The ESP32-S3 SDK, the en-1 model and the threshold generator are in release v0.1.0, free for non-commercial use. For a product you sell, get a commercial licence.

The component builds the engine from the repository checkout, so clone it and point EXTRA_COMPONENT_DIRS at sdk/esp32/wake. Embed the model as model.pwake (EMBED_FILES in main/CMakeLists.txt) and your keyword file with EMBED_TXTFILES; demos/esp32 in the repository is a complete project.
