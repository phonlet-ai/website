Start with a sound.

What Phonlet Wake is, what you can try today, and how to get your own phrase.

Phonlet Wake detects wake words on the device. One acoustic model recognises the sounds of English speech; each wake word is a small entry of pronunciations and thresholds made from text. You can try it now without an account, API key, or download.

1. Try your phrase

Type it in the lab, start listening, and say it out loud.

2. Follow the code

Load the SDK with the model and a keyword file, then pass it audio.

3. Understand your phrase

Pronunciations, calibrated thresholds, sensitivity, and quality checks.

4. Make your keyword file

Every phrase you need in one file, made in your browser, for every SDK.

What you need for the lab

A current browser with WebAssembly, AudioWorklet, and microphone support. Microphone capture requires HTTPS or localhost.
